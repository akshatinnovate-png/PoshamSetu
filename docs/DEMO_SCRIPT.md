# Demo script — Round 2, 10 minutes + 5 minutes Q&A

Start the app with `npm start` (or run the packaged build). Wait for the boot log, then press **`j`** to start the Jury tour. Each step's talking points appear on the caption bar. Use **→ / ←** to move between steps. The clicks below are the live moments that make the demo land.

| Time | Step | What to do on screen |
|---|---|---|
| 0:00 | The gap | Home is open. Scroll once to the giant "Do Not Wait…" headline. |
| 0:40 | Who it is for | The Brief opens on Stakeholders. Point at the AWW and migrant-mother cards. |
| 1:00 | Architecture | Click **Event bridge**, then **L3 Act**. Each shows its audit fix and code file. |
| 2:00 | A child, explained | Point at the WHZ trajectory and the "Why this tier" panel (rule + pack version). |
| 2:40 | Same child, two systems | The comparison replays by itself. Pause on the row where PoshanSetu says AMBER and the Tracker says "not listed". |
| 3:00 | Silent trial | Read both numbers: flagged before the SAM list, and before *any* listing. Optionally press **Robustness** (takes about 4 s). |
| 4:00 | Fix 01 bridge | Toggle **Round 1 → Fallback → Round 2**. Point at the clock-safety matrix. |
| 4:40 | Fix 01 live | A RED-A event is sent automatically. The toast shows it arriving by SMS flash with a 24 h deadline from measurement. |
| 5:00 | Fix 01 offline | On the AWW phone: **Offline** → tap a child → tick oedema → **Save** → **+6 h** (×5) → **Online**. Open the Worklist: the task shows *late arrival* at L1. |
| 5:40 | Fix 02 joint visit | Press **☎ CALL** on the phone, then **1**. The state machine moves to half-closed or closed. |
| 6:30 | Fix 03 migration | **Verify offline** → **Tamper 1 byte** → **Verify** (rejected). Untick everything except "AWC tablet has data" → **Scan mother's thumb**. |
| 7:20 | Fix 04 R-score | Point at the red squares (decimal-slip AWCs) dropping below the cutoff line. Drag **wB** down to show the old behaviour returning. |
| 8:10 | Fix 05 budget | Point at "What Rs 12 L buys" vs the dark Phase 3 capex strip. |
| 8:50 | Governance | Ladder lanes, then **Role → DPO**: views collapse to aggregates. Optional: Rule pack → move a slider → sign as both ministries → **Activate**. |
| 9:30 | Close | Home. One line: *watch which way the child is heading, and act while recovery is still simple.* |

## If something goes wrong

- **Tour stuck:** press `×` on the caption bar, then `j` again.
- **Lost a window:** Layout → Close all windows, then reopen it from the dock.
- **Clock moved too far:** Time → Reset to 17 Nov 2026 09:00.
- **No laptop / projector issue:** the web build (`npm run serve`) and the screenshots in `docs/screens/` are backups.

## Q&A

Keep `docs/JURY_QA.md` open on a second device. Every answer points to a window you can open in one click (shortcuts: `1`–`5` for the fixes, `t` trial, `r` rule pack, `k` consent, `p` report).
